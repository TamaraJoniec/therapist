# Daniella Britto - Terapia para Mães

Uma landing page elegante e responsiva para Daniella Britto, psicóloga especializada em saúde materna e perinatal no Rio de Janeiro, Brasil.

## 🌟 Sobre o Projeto

Este é um website profissional desenvolvido para Daniella Britto, psicóloga especializada em terapia para mães. O site apresenta seus serviços de forma elegante e acolhedora, refletindo o cuidado e a atenção que ela dedica às suas pacientes.

### ✨ Características

- **Design Responsivo**: Otimizado para desktop, tablet e mobile
- **Interface Elegante**: Paleta de cores suaves inspirada na maternidade
- **Formulário de Contato**: Integração com Formspree para envio de emails
- **Seções Informativas**:
  - Sobre Daniella
  - Serviços oferecidos
  - Como funciona a terapia
  - Depoimentos de pacientes
  - Informações de contato
- **Animações Suaves**: Transições elegantes e micro-interações
- **SEO Otimizado**: Estrutura semântica HTML

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estrutura semântica
- **CSS3**: Estilos modernos com variáveis CSS
- **Google Fonts**: Cormorant Garamond e DM Sans
- **Formspree**: Processamento de formulários
- **SVG**: Ilustrações vetoriais

## 🚀 Como Começar

### Pré-requisitos

- Navegador web moderno
- Conexão com internet (para fontes Google Fonts)

### Instalação

1. **Clone o repositório:**

   ```bash
   git clone https://github.com/TamaraJoniec/therapist.git
   cd therapist
   ```

2. **Abra o arquivo:**
   - Abra `index.html` diretamente no navegador, ou
   - Use um servidor local para desenvolvimento

3. **Para desenvolvimento local (opcional):**

   ```bash
   # Usando Python
   python -m http.server 8000

   # Ou usando Node.js
   npx serve .
   ```

4. **Acesse:** `http://localhost:8000`

## 🌐 Deploy

### Netlify (Recomendado)

1. **Conecte seu repositório GitHub ao Netlify:**
   - Acesse [netlify.com](https://netlify.com)
   - "New site from Git" → GitHub
   - Selecione o repositório `therapist`

2. **Configurações automáticas:**
   - Netlify detectará automaticamente as configurações do `netlify.toml`
   - Build command: (vazio - site estático)
   - Publish directory: `.` (raiz do projeto)

3. **Deploy automático:**
   - Toda alteração no branch `main` será automaticamente implantada

### Outras Opções

- **GitHub Pages**: Configure nas configurações do repositório
- **Vercel**: Importe o repositório e faça deploy automático
- **Surge**: `surge .` no terminal
